Professional Summary

김효중은 2025년 SaaS HR 플랫폼 WORKUP 영업을 담당하며, 제품 소개에 그치지 않고 고객의 인사·조직·급여·근태·평가·전자계약 요구를 확인하고 표준 기능, 옵션, 고도화 가능성, API 연계 범위를 구분해 도입 판단을 지원했습니다.

특히 데모와 트라이얼 단계에서 사용자 계정 문제, 기능 동작 문의, 데이터 반영 주기, 결재선 설정 등 실제 검증 과정의 질문을 직접 정리하고 내부 제품·서비스 담당자와 연결하여 대응했습니다. 고객이 즉시 계약하지 않거나 경쟁 제품을 선택한 경우에도 검토 상태를 확인하고 관계를 유지하는 파이프라인 관리 업무를 수행했습니다.

구축형 검토 고객을 SaaS 대안으로 전환 제안

고객사 주성엔지니어링 · 2025.11
Lead Conversion
상황
기존에 구축형 HR을 검토한 고객에게 구독형 대안의 적합성과 비용 구조를 새롭게 설명해야 했습니다.
수행
전체 모듈 기준 견적, 연 선납 할인, 생산직 할인 협의 가능성, 데이터 이관 범위, 무료 체험과 기능 시연을 한 번에 정리했습니다.
해결 방식
커스터마이징 제약을 숨기지 않고 표준 옵션, 공통 고도화, 특정 고객 전용 기능의 제한을 구분했습니다. 외부 시스템 연계는 API 제공과 상대 시스템 개발 역할을 명확히 안내했습니다.
가치
구축형과 SaaS의 차이를 고객 의사결정 항목으로 전환하고, 가격·기능·연계 책임을 사전에 투명하게 제시했습니다.

제조 고객의 복합 HR 요구에 맞춘 모듈·가격 제안

고객사 C사 · 2025.08–11
Demo & Proposal
상황
인사·급여·근태뿐 아니라 평가와 전자계약을 함께 검토했고, 생산직 인원에 대한 비용 부담과 탄력근로제 적용 여부도 중요했습니다.
수행
방문 기능시연을 진행하고, 데모 계정과 매뉴얼, 의사결정권자용 구축사례 자료를 제공했습니다. 평가·전자계약 포함 견적을 별도로 제시하고 모듈별 선택이 가능하도록 구성했습니다.
문제 대응
데모 로그인 오류가 발생했을 때 계정 상태를 확인하고 초기화해 검토가 중단되지 않도록 했습니다. 현장직 대상 할인안을 반영하여 가격 부담도 조정했습니다.
가치
기능 설명, 제도 적합성 확인, 체험 운영, 가격 조정을 하나의 고객 여정으로 연결했습니다.

트라이얼과 UAT 중심의 실제 사용 검증 지원

고객사 M사 · 2025.09–11
Trial Support
상황
고객 현업이 결재선, 연차, 데이터 반영 주기 등 실제 운영 시나리오를 집중 검증하려 했으나 휴일 일정과 자료 부족으로 테스트가 지연됐습니다.
수행
트라이얼 기간을 연장하고 샘플 데이터가 포함된 테스트 환경과 사용 가이드를 제공했습니다. 결재선 기능, 즉시·일괄 반영 항목, 긴급 반영 방법에 관한 질문을 정리해 답변했습니다.
해결 방식
테스트 중 발생한 현상이 설정 문제인지 제품 제약인지 구분할 수 있도록 현장 검증을 제안하고, 필요한 설정을 처리한 뒤 재테스트를 요청했습니다.
결과
최종적으로 타사가 선정됐지만, 고객의 결과 통보까지 검토 상태를 지속 확인하고 협업 가능성을 남기는 방식으로 마무리했습니다.

What I Solved

SaaS 적합성 불확실성

표준 기능, 선택 옵션, 공통 고도화, 고객 전용 개발 제한을 구분하여 고객이 현실적인 도입 범위를 판단하도록 지원했습니다.

연계 책임의 모호함

WORKUP이 제공하는 API 가이드와 외부 시스템 측 개발 역할을 분리해 연계 비용과 책임 주체를 명확히 했습니다.

데모 검토 중단 위험

계정 오류, 검토기간 부족, 샘플 시나리오 부족 문제에 데모 계정 재설정, 기간 연장, 샘플 환경 제공으로 대응했습니다.

복합 요구와 예산 간 충돌

모듈별 선택 견적과 직군별 할인안을 제안해 필수 기능과 비용을 함께 조정할 수 있도록 했습니다.

기능 동작에 대한 불신

결재선과 데이터 반영 주기 등의 질문을 세분화하고 설정·기능 제약 여부를 확인하여 재검증 가능한 답변으로 전환했습니다.

장기 의사결정 지연

진행상황을 주기적으로 확인하고 추가 질문 창구를 유지해, 검토 보류 고객도 파이프라인에서 관리했습니다.
